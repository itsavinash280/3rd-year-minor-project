# Environment Setup Guide — AsraVerse AI

## Environment Variables Reference

| Variable | Description | Default / Example |
|---|---|---|
| `PORT` | Backend Express HTTP port | `5000` |
| `MONGODB_URI` | MongoDB Connection String | `mongodb://127.0.0.1:27017/asraverse` |
| `JWT_SECRET` | Secret key for signing Access Tokens | `asraverse_super_secret_jwt_key_2026_safe` |
| `JWT_REFRESH_SECRET` | Secret key for Refresh Tokens | `asraverse_refresh_secret_key_2026_safe` |
| `GOOGLE_CLIENT_ID` | OAuth Client ID from Google Cloud Console | `google_client_id_placeholder` |
| `GOOGLE_CLIENT_SECRET` | OAuth Client Secret | `google_client_secret_placeholder` |
| `CLOUDINARY_CLOUD_NAME` | Cloudinary Cloud name for image storage | `cloudinary_cloud_placeholder` |
| `CLOUDINARY_API_KEY` | Cloudinary API Key | `cloudinary_key_placeholder` |
| `CLOUDINARY_API_SECRET`| Cloudinary Secret | `cloudinary_secret_placeholder` |
| `WEATHER_API_KEY` | OpenWeather / IMD Agromet API Key | `weather_key_placeholder` |
| `RAZORPAY_KEY_ID` | Razorpay Merchant ID for Escrow Payments | `rzp_test_placeholder_key` |
| `RAZORPAY_KEY_SECRET` | Razorpay Merchant Secret | `rzp_test_placeholder_secret` |
